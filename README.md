# [Cullen Molitor's Personal Website](https://cullen-molitor.github.io/)

Built with [Quarto](https://quarto.org). The rendered site lives in `docs/` and is served by GitHub Pages.

```bash
quarto preview      # live local preview
quarto render       # rebuild docs/ before committing
```

- `index.qmd`: home page
- `cv.qmd`: web CV (PDF in `cv/`)
- `blog.qmd`: blog listing; each post is `posts/<date-slug>/index.qmd`
- `photos.qmd`: photo gallery
